# HƯỚNG DẪN THÊM ẢNH — BD001 MA CHÉRIE

## Tổng cộng cần: 4 ẢNH (tối thiểu) — tối đa 13 ảnh

### 1. ẢNH BÌA (bắt buộc — 1 ảnh)

| File           | Mô tả                        | Tỷ lệ khuyên dùng |
|----------------|-------------------------------|--------------------|
| `cover.jpg`    | Ảnh chân dung người nhận      | Dọc 4:5            |

> Ảnh này hiển thị lớn ở màn hình THE COVER. Nên chọn ảnh đẹp, chất lượng cao.

### 2. ẢNH ALBUM (bắt buộc — tối thiểu 3 ảnh, tối đa 12 ảnh)

| File           | Mô tả                        | Tỷ lệ             |
|----------------|-------------------------------|--------------------|
| `photo1.jpg`   | Kỷ niệm 1                    | Tự do              |
| `photo2.jpg`   | Kỷ niệm 2                    | Tự do              |
| `photo3.jpg`   | Kỷ niệm 3                    | Tự do              |
| `photo4.jpg`   | (tùy chọn)                   | Tự do              |
| ...            | Thêm đến photo12.jpg         | Tự do              |

> Ảnh album tự động crop phù hợp, kích thước nào cũng được.

### 3. NHẠC NỀN (tùy chọn — 1 file)

Đặt vào thư mục `assets/audio/`:

| File              | Mô tả          |
|-------------------|-----------------|
| `background.mp3`  | Nhạc nền nhẹ    |

## SAU KHI THÊM ẢNH

Mở file `js/config.js` để chỉnh caption cho từng ảnh album.
